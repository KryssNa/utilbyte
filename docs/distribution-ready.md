## Concrete release message

UtilByte's SQL Formatter now uses explicit dialects and has a reproducible regression suite covering quoted whitespace, comments, escaped quotes, identifiers, and parameters. We also added contextual tool navigation, draft-loss prompts, and three local JSON workflows: JSON ↔ CSV, draft-07 schema validation, and TypeScript type inference.

The implementation documents its limits: formatting does not validate SQL execution, CSV text mode can change type information, and inferred TypeScript is not runtime validation. We'd like feedback on finding related tools and preserving editor space, especially from keyboard and mobile users.
